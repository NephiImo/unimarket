# UniMarket

UniMarket is a student marketplace that allows university students to buy and
sell items within their school community.

## Project Description

UniMarket provides students with a simple platform to create accounts, post
items for sale, browse and search listings, manage their own listings, and
send inquiries to sellers.

## Technology Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
